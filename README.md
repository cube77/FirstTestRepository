# Automotive Voice Defect Reporter – Sprint 1.7

Full Xcode SwiftUI project for iPhone. This update fixes test-drive navigation and iPhone layout based on Sprint 1.6. Recording and playback code is unchanged.

## Install
Open `AutomotiveVoiceDefectReporter.xcodeproj` in Xcode. Select the connected iPhone, choose your Personal Team under Signing & Capabilities, and run (Cmd+R). Keep the Bundle Identifier unchanged to retain the existing app's local SwiftData store and recordings.

See `SPECIFICATION_SPRINT_1_7.md` for details and test steps. Xcode build and device behavior must be verified on a Mac.
